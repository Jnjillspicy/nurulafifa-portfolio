# Nurul Afifa — Creative Portfolio

A responsive single-page portfolio website built from the supplied Canva portfolio.

## Files
- index.html
- style.css
- script.js
- assets/ — portfolio evidence and cropped visuals

## Run locally
Open `index.html` in a modern browser.

## Before client delivery
1. Replace the cropped profile image with a high-resolution original portrait if available.
2. Replace portfolio evidence with original screenshots/files where possible.
3. Add real video URLs/files for the Talent section if available.
4. Add a final CV PDF and change the CTA to point to it.
5. Confirm email, WhatsApp and Instagram details with the client.
6. For production, host with HTTPS.
